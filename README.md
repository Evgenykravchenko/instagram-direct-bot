# Instagram Direct Bot

Бот для автоматической выдачи текста, фотографий, видео, аудио и кнопок в Instagram
Direct по ключевым словам. Контент меняется в общей Directus CMS без правок кода.

Проект следует тем же правилам, что VK- и Telegram-боты платформы: отдельный адаптер
канала, единая CMS, исходники на Яндекс Диске, Docker-образ для `linux/arm64`,
SemVer-релизы и развёртывание только из опубликованного образа.

## Как работает

```text
Instagram → проверенный webhook → PostgreSQL-очередь → поиск ключевой фразы
                                                       ↓
                 Instagram ← Meta Send API ← ответ из Directus

Яндекс Диск → media worker → Meta Attachment Upload → attachment_id в Directus
```

Webhook подтверждается только после записи события в PostgreSQL. Повторная доставка от
Meta безопасна: идентификатор события уникален. Готовый ответ сохраняется снимком, а
позиция отправки обновляется после каждого сообщения — уже отправленные части не
повторятся после перезапуска.

## Возможности

- точное совпадение, фраза внутри текста, любое или все слова;
- приоритеты правил и общий fallback;
- ответы из нескольких текстовых и медиаблоков;
- кнопки-команды и кнопки-ссылки;
- фото, видео и аудио без постоянного хранения на сервере;
- очередь с повторными попытками для временных ошибок Meta;
- проверка `X-Hub-Signature-256`, лимит тела webhook и безопасные логи;
- healthcheck, graceful shutdown и запуск контейнера без root.

## Быстрый локальный запуск

Понадобятся Node.js 22+, Docker и доступ к уже запущенной Directus CMS.

```shell
cp .env.example .env
npm ci
npm run typecheck
npm test
docker compose up --build
```

После запуска healthcheck доступен на `http://127.0.0.1:8091/health`. Для настоящего
webhook нужен временный HTTPS-адрес, который проксирует запросы на локальный порт. Не
публикуйте callback до прохождения локальных тестов.

## Статус

Код и локальная инфраструктура готовы к тестированию. Развёртывание на Raspberry Pi и
регистрация production webhook намеренно не выполнялись. Перед первым релизом нужен
живой тест с профессиональным Instagram-аккаунтом и действующим Meta access token.
