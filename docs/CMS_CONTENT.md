# Контент Instagram-бота в CMS

Эта инструкция рассчитана на редактора. Технические коллекции и идентификаторы Meta
заполнять вручную не нужно.

## Из чего состоит выдача

1. **Content Bots** — выберите `Instagram Direct Bot`.
2. **Responses** — готовый ответ, который получит человек.
3. **Response Blocks** — текст, фото, видео или аудио внутри ответа.
4. **Response Buttons** — действия под ответом.
5. **Keywords** — фразы, по которым выбирается ответ.
6. **Bot Settings** — сообщение на случай, если ничего не подошло.

Во всех записях выбирайте одного и того же бота. Чужой контент процесс не увидит.

## Только текст

1. В **Responses** создайте ответ и пока оставьте `Draft`.
2. В **Response Blocks** создайте блок `Text`, выберите ответ и напишите текст.
3. В **Keywords** добавьте фразу, тип совпадения и выберите ответ.
4. Вернитесь в ответ и поставьте `Published`.

Пример: ключ `расписание`, ответ `Ближайший эфир — в четверг в 19:00.`

## Текст и фотография

1. Загрузите оригинал на Яндекс Диск, например `/Bot Content/Instagram/guide.jpg`.
2. В **Media Assets** создайте материал:
   - Bot — Instagram Direct Bot;
   - Kind — `Photo`;
   - Yandex Path — точный полный путь;
   - Status — `Queued`.
3. Подождите, пока статус станет `Ready`.
4. Добавьте в ответ текстовый блок и блок `Photo`; в поле Media выберите материал.
5. Опубликуйте ответ и привяжите ключевое слово.

Worker сам получает файл с Яндекс Диска, один раз подготавливает его в Meta и сохраняет
технический ID. Файл не остаётся на диске Raspberry Pi. До истечения ID Яндекс Диск не
используется при пользовательских запросах; worker обновляет ID заранее.

## Видео или аудио

Действия те же, но в **Media Assets** выберите `Video` или `Audio`, а в блоке ответа —
тот же тип. Формат и размер должны укладываться в актуальные ограничения Instagram
Messaging API. Если Meta отклонит файл, в поле Error Message появится причина.

Документы Instagram Direct как вложения не поддерживает. Для PDF или архива добавьте
обычную HTTPS-ссылку в текст ответа или кнопку-ссылку.

## Кнопки

В **Response Buttons** доступны два действия:

- `Command` — отправляет боту другую ключевую фразу, например `цена`;
- `Open Link` — открывает полный адрес вида `https://example.com/page`.

Instagram показывает не больше трёх кнопок в одном шаблоне. Если кнопок больше, бот
автоматически разобьёт их на несколько сообщений. Цвет и номер ряда в Instagram не
отображаются, но порядок сохраняется. Короткая подпись выглядит лучше; длинная будет
аккуратно сокращена.

## Fallback

В **Bot Settings** есть два варианта:

- Unknown Message — один короткий текст;
- Fallback Response — полноценный опубликованный ответ с блоками и кнопками.

Если указан Fallback Response, он имеет приоритет. Это удобно для меню с кнопками.

## Типы совпадения

| Режим     | Пример ключа     | Когда сработает                   |
| --------- | ---------------- | --------------------------------- |
| Exact     | `цена`           | сообщение равно слову `цена`      |
| Contains  | `получить гайд`  | фраза встречается целиком         |
| Any word  | `цена стоимость` | найдено хотя бы одно слово        |
| All words | `курс питание`   | найдены оба слова в любом порядке |

Если подходит несколько правил, побеждает правило с большим Priority.

## Перед публикацией

- проверьте владельца Bot у ответа, ключа и медиа;
- дождитесь `Ready` у каждого материала;
- откройте все ссылки;
- проверьте fallback неизвестной фразой;
- только после этого переключите ответ в `Published`.

Коллекция **Media Deliveries** служебная. Она заполняется автоматически и редактору не
нужна.
