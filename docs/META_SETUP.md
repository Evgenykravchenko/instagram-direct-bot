# Настройка Meta и Instagram

Для работы нужен профессиональный Instagram-аккаунт и приложение в Meta for Developers
с Instagram API и доступом к сообщениям.

## Что подготовить

| Переменная               | Что это                                        | Где взять                                                           |
| ------------------------ | ---------------------------------------------- | ------------------------------------------------------------------- |
| `INSTAGRAM_ACCOUNT_ID`   | числовой ID профессионального аккаунта         | Meta App Dashboard / Instagram API setup                            |
| `INSTAGRAM_ACCESS_TOKEN` | long-lived токен с доступом к сообщениям       | раздел генерации токена Instagram Login                             |
| `INSTAGRAM_APP_SECRET`   | секрет приложения для проверки подписи webhook | App settings → Basic                                                |
| `INSTAGRAM_VERIFY_TOKEN` | придуманная вами случайная строка              | сгенерировать локально и одинаково указать в Meta и `.env`          |
| `META_GRAPH_VERSION`     | версия Graph API                               | оставить значение проекта или обновить после проверки release notes |

Токену требуется разрешение `instagram_business_manage_messages`. Получатель должен
сам начать переписку с профессиональным аккаунтом — бот не может произвольно написать
любому пользователю.

## Webhook

Callback имеет вид:

```text
https://ваш-домен.example/webhook
```

При сохранении Meta отправляет GET-запрос. Бот сравнивает verify token и возвращает
challenge. Все POST-запросы дополнительно проверяются HMAC-подписью приложения.

Для первого локального теста используйте временный HTTPS-туннель. Production URL через
Tailscale Funnel добавляется только при серверном развёртывании.

## Важно о токенах

- не вставляйте секреты в README, issue или логи;
- `.env` уже исключён из Git;
- если токен попал в историю Git, отзовите его, а не просто удалите строку;
- до production обязательно проверьте срок жизни токена и процедуру его обновления.

Официальные примеры запросов находятся в коллекции
[Meta Instagram API](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api).
